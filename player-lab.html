How this version handles errors

The WASM engine attempts MKV playback first. Version 0.4.1 can hand a source to native browser playback when the WASM fetch path fails. Native fallback may play a cross-origin file that lacks CORS headers, but native browser playback usually cannot decode MKV or expose its embedded tracks. The source server must allow browser-readable requests for full MKV track support.

If the link still fails, it may be expired, require special headers, or the host may block browser requests. This lab does not proxy media or change your production website.
