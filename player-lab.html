Compatibility notes

This is an isolated player prototype, not yet wired into the live MaseNet catalogue. Browser playback cannot guarantee every codec or every URL. Remote servers must permit cross-origin access (CORS), and URL-based seeking commonly requires HTTP Range support. DRM-protected streams, expiring links, and unsupported codecs need separate handling.

For maximum format coverage like desktop VLC, the long-term route is a native Android app using libVLC. A website player can cover many direct streams and MKV tracks, but it cannot honestly promise every stream will play in every browser.
